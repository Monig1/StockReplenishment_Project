# Stock Replenishment Request System

A Blazor Web App for creating, submitting, approving, rejecting and fulfilling stock replenishment requests.

## Technologies

- .NET 10
- Blazor Web App
- Interactive Server Rendering
- MudBlazor
- Entity Framework Core
- SQL/EF Core In-Memory database
- NUnit
- NSubstitute
- REST APIs
- Background Worker

## Project Structure

- StockReplenishment - Main Blazor application
- StockReplenishment.Tests - Unit tests
